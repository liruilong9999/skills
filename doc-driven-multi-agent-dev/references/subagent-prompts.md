# 子智能体提示模板

## 1. 实现型子智能体

```text
基于以下文档与约束实现当前任务，只处理分配范围内内容，不重定义接口和数据模型。

任务：
- [任务名称或 TASK-ID]

必读文档：
- [路径 1]
- [路径 2]

分支策略：
- [是否创建分支]
- [分支名或由主智能体创建]

允许修改：
- [文件或目录]

禁止修改：
- [文件或目录]

完成标准：
- [标准 1]
- [标准 2]

返回内容：
- 修改摘要
- 关键实现点
- 验证结果
- 风险与待主智能体处理事项
```

## 2. 测试型子智能体

```text
基于指定需求、设计和实现结果补齐测试，只覆盖当前分工范围，不擅自改功能实现。

测试范围：
- [范围]

必读文档：
- [路径]

分支策略：
- [通常不建分支；如需写测试代码则写明]

允许修改：
- [测试目录]

返回内容：
- 新增或更新的测试
- 覆盖的验收点
- 未覆盖项与原因
```

## 3. 审查型子智能体

```text
仅做审查，不做实现。根据需求、设计、接口契约和测试用例检查当前变更是否越界、漏项或冲突。

检查依据：
- [需求文档]
- [设计文档]
- [接口文档]
- [测试文档]

分支策略：
- [默认不创建分支]

输出要求：
- 按严重程度列出问题
- 指出对应文件和原因
- 明确哪些地方需要回主智能体决策
```

## 4. 文档同步型子智能体

```text
只同步当前任务相关文档，不修改未分配实现。确保需求、设计、接口、任务拆解和测试用例描述保持一致。

输入：
- 当前任务说明
- 已完成实现或测试结果

分支策略：
- [通常不建分支；如需同步文档且会落盘修改则写明]

输出：
- 需要同步的文档点
- 已更新内容
- 仍待确认的冲突项
```
